# 加工厂版（可直接导入 CAM）

三张**纯净切割版** DXF —— 只含真正的激光切割轮廓（CUT/FLANGE/HOLE/HATCH 四层），
已删除：文字标注、尺寸线、中心线、折弯辅助图形、装饰 SOLID、折弯层。

## 文件清单
| 文件 | 内容 | 切割路径 |
|---|---|---|
| 灯壳_切割版_600x300.dxf | 灯壳展开（4面散热孔+顶部圈孔+法兰孔） | ≈13.7m |
| 端板A_切割版_150x150.dxf | 外端板（Ø100+4×Ø7+3卡口） | ≈1.6m |
| 端板B_切割版_150x150.dxf | 中间端板（Ø100+4×Ø7） | ≈1.5m |

## CAM 导入说明
1. 加载 DXF 后**勾选所有图层**即可（已无杂质，放心全选）
2. 单位 mm，板厚 2mm，304 不锈钢（氮气切割防氧化）
3. 建议切割顺序：先小孔/槽 → 散热孔 → 最后外轮廓
4. 灯壳外轮廓长，建议留 2~3 处 0.5mm 微连接防翘起
5. 折弯线未包含（折弯机按原图 y=0/4/269 折）

## 与原始版区别
原图含标注/文字/SOLID装饰/板外辅助线，CAM 全选会误切；本版删净，模拟走刀即所见即所得。
