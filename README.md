# 保荣摄影灯外壳 (Baorong Lamp Shell)

摄影灯金属外壳钣金件图纸 —— 2mm 304 不锈钢，激光切割下厂即用。

## 文件清单（最终版 2026-10-05）

| 文件 | 零件 | 说明 |
|---|---|---|
| `灯壳_洞洞板展开_600x300.dxf` | 灯壳展开板 600×300 | 78 个长圆散热孔 5×30(R2.5)，间距7mm，凸圆两端 |
| `端板A_带卡口_150x150.dxf` | 端板A（最外端板·带卡口） | 3×8×8 卡口内边与 Ø100 圆周重合，单轮廓一刀走完 |
| `端板B_中间板_150x150.dxf` | 端板B（中间端板·无卡口） | Ø100 透光孔 + 4×Ø7 |
| `*_预览.png` | 预览图 | 带水印「天涯何处不相逢」 |

## 图层规范（CAM 导入后按层分配工艺）

| 图层 | 颜色 | 含义 | 工艺 |
|---|---|---|---|
| CUT | 红(1) | 外轮廓 / 切割线 | 切割 |
| FLANGE | 红(1) | 法兰 / 卡口 | 切割 |
| HOLE | 绿(3) | 螺丝孔 Ø7 | 切割 |
| HATCH | 蓝(5) | 散热孔（长圆孔） | 切割 |

**本仓库 DXF 均为纯切割净版（R12/AC1009）**：无文字、无标注、无辅助线，导入 CAM 后不会切到任何非切割元素。尺寸参数见预览图与加工文档。

## 加工参数

- 材料：304 不锈钢 2mm
- 文件单位：mm，1:1
- 切缝补偿：由 CAM 统一设置（图纸为标称尺寸，勿双重补偿）
- 散热孔：78 × 长圆孔 5×30（R2.5），净距 ≥7mm
- 卡口：端板A 3×8×8 @ 90°/210°/330°，内边与 Ø100 圆周对齐，一刀走完

## 生成

`gen_cad.py` 为参数化生成脚本（改顶部 CONFIG 后 `python gen_cad.py` 重新出图）。
