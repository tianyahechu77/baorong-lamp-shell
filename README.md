# 保荣摄影灯外壳 (Baorong Lamp Shell)

摄影灯金属外壳钣金件图纸 — 1mm 不锈钢，激光切割下厂即用。

## 文件清单（最终版 2026-10-17）

| 文件 | 零件 | 说明 |
|---|---|---|
| `灯壳.dxf` / `灯壳_参数.png` / `灯壳_预览.png` | 灯壳展开板 600×300 | 75 散热孔（两端圆头长圆孔），含尺寸标注参数图与预览图 |
| `端板A.dxf` / `端板A_参数.png` / `端板A_预览.png` | 端板A | 最外端板，含卡口 |
| `端板B.dxf` / `端板B_参数.png` / `端板B预览.png` | 端板B | 中间端板 |
| `垫片.dxf` / `垫片_参数.png` / `垫片_预览.png` | 垫片 | 60×70 |

每零件三件套：DXF（切割用）+ 参数图（尺寸标注）+ 预览图（带水印「天涯何处不相逢」）。

## 加工参数

- 材料：1mm 不锈钢
- 文件单位：mm，1:1
- 切缝补偿：由 CAM 统一设置（图纸为标称尺寸，勿双重补偿）

## 生成

`gen_cad.py` 为参数化生成脚本（改顶部 CONFIG 后 `python gen_cad.py` 重新出图）。
