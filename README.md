## DXF 图层规范

| 图层 | 含义 | 处理 |
|---|---|---|
| `CUT` | 实体切割轮廓、标题栏 | 激光切割走这层 |
| `FLANGE` | 红色实线：法兰线切口段、折线顶端/底端切口 | 全切开 |
| `BEND` | 折弯线（虚线点划线）、法兰基准线、接缝线 | 折弯机用，不切 |
| `HOLE` | Ø7 通孔 | 冲孔/钻孔 |
| `HATCH` | 预留散热孔阵 | 按需冲孔 |
| `CENTER` | 中心线 | 参考 |
| `DIM` / `TEXT` | 尺寸标注与文字 | 不加工 |

## 关键尺寸（对应参考图）

- 展开板 600 × 300（= 4 × 150 面）
- 折弯线 x = 150 / 300 / 450（蓝虚线，y 0~265）；左右两端为接缝
- 法兰线 y = 269（距底 31mm），蓝虚线全宽；红色实线段=切口（**统一 3cm 对称**）：`0-30 / 135-165 / 285-315 / 435-465 / 570-600`
- 折线顶端红色切口 18mm × 3；折线底端红色切口 246~300mm × 3（穿透法兰，折叠让位）
- "30mm 法兰·沿此线内折 90°（四角双层重叠）"说明文字为**蓝色**（与折线虚线同色，属 BEND 图层）
- 法兰孔 8×Ø7 @ y=285：x = 15 / 135 / 165 / 285 / 315 / 435 / 465 / 585
  （每道折线/接缝两侧各 1 个，距线 15；折后四角各 2 孔与端板角孔对齐，内折 90° 四角双层重叠）
- 端板 150×150，中心 Ø100，四角 Ø7（距边 15）
- 端板 A 带卡口 3×8×8 @ 90°/210°/330°（位于 Ø100 圆周）
- 料厚 2mm 不锈钢，

## 改参数

编辑 `gen_cad.py` 顶部 `CONFIG` 区：

```python
W_ALL, H_ALL = 600.0, 300.0    # 展开板总宽 x 总高
FLANGE_Y = 269.0               # 法兰线 y（距顶）
HOLE_D = 7.0                   # 螺钉孔径
HOLE_EDGE = 15.0               # 孔心距折线/板端
NOTCH_TOP = 18.0               # 折线顶端切口长
NOTCH_BOT = [246,247,249]      # 折线底端切口起点 y
FLANGE_CUTS = [(0,25),...]     # 法兰线红色切口段
COOL_HOLE = None               # 散热孔: None=不画; 如 (10.0, 25.0)=Ø10@25等边三角阵
```

散热孔当前"孔径/间距待定"，确认后设 `COOL_HOLE = (孔径, 孔距)` 重跑即可出孔阵图。

## 散热孔设计 (灯壳展开图)

- 靠法兰侧 4 面开孔: 开孔区 110×110 (每面 150×150 区域内四周留 2cm 边缘)
  - x: 面起点+20 ~ +130, y: 140 ~ 250
- 孔型: 圆头长条孔 30×5mm, 间隔 7mm (斜孔法向), 横/竖交错阵列净距 10mm
- 分配: F1 斜45°正 / F2 横 / F3 斜45°反 / F4 竖
- 另一端顶部: 距顶边 2cm, 每面 3 个短长孔 30×5 (一圈共 12)
- 参数在 gen_cad.py 顶部 VENT 字典修改
